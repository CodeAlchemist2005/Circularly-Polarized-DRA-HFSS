# Circularly Polarized Dielectric Resonator Antenna Using HFSS

## Overview

This project presents the design and simulation of a Circularly Polarized Dielectric Resonator Antenna (CP-DRA) using Ansys HFSS.

The antenna employs a cross-slot feeding mechanism to generate circular polarization and improve radiation performance.

## Objectives

* Design a CP-DRA antenna
* Analyze S11 characteristics
* Evaluate axial ratio
* Study radiation pattern
* Determine antenna gain

## Software Used

* Ansys HFSS 2025 R2

## Antenna Components

* Substrate
* Ground Plane
* Feed Line
* Cross Slot
* Dielectric Resonator

## Results

| Parameter          | Value    |
| ------------------ | -------- |
| Resonant Frequency | 3.88 GHz |
| S11                | -24 dB   |
| Axial Ratio        | 1.2 dB   |
| VSWR               | 1.13     |
| Bandwidth          | 500 MHz  |

## Applications

* Satellite Communication
* GPS Systems
* Wireless Communication
* 5G Systems
* Radar Systems
